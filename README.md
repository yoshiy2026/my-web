# Loko Pono ランディングページ

「浩子ちゃんのLP台本_最終案.docx」をベースに作成した、PC／スマートフォン両対応の
1ページ完結型ランディングページです。

## ファイル構成

```
lp/
├─ index.html              ... ページ本体（これをブラウザで開けば表示されます）
├─ terms.html              ... 利用規約・キャンセルポリシー
├─ tokushoho.html          ... 特定商取引法に基づく表記
├─ privacy.html            ... プライバシーポリシー
├─ README.md               ... このファイル
└─ assets/
   ├─ css/style.css        ... デザイン一式
   ├─ js/main.js           ... ドロワーメニュー、スクロール演出、予約フォームの入力チェックと送信
   └─ img/
      ├─ profile.png       ... 顔.png（プロフィール写真）
      └─ room.jpg          ... room.jpeg を Web 用に軽量化（1.7MB → 430KB）
```

外部依存は Google Fonts のみです。ビルド作業は不要で、そのままサーバーへ
アップロードすれば公開できます。

## 確認方法

index.html をダブルクリックしてブラウザで開いてください。
スマートフォン表示は、ブラウザの開発者ツール（F12）のデバイスモードで確認できます。

## デザインの方針

台本の「ナチュラル、自然、親しみやすさ、静けさ」「森の中の光、木漏れ日」という
ご要望をもとに、以下で構成しています。

- 配色：淡いターコイズブルー、アースカラー、白、緑、茶
- 書体：見出しに明朝体（Shippori Mincho B1）、本文にゴシック体（Zen Kaku Gothic New）、
  英字に Cormorant Garamond
- 木漏れ日を思わせる光のグラデーションと、ゆっくり揺れる葉のモチーフ
- 相談室の写真はアーチ型に切り抜き、窓から覗くような印象に

## 公開前にご対応いただきたい箇所

台本で「要確認」となっていた項目、および仮リンクのままの箇所です。

1. ロゴ
   現在は葉をかたどった図形で仮表示しています（CSS の `.logo__mark`）。
   ロゴ画像が完成したら `<span class="logo__mark">` を `<img>` に差し替えてください。
   該当箇所：index.html のヘッダーとフッターの2か所。

2. フォームの送信先（Formspree）
   index.html 冒頭の `FORM_ENDPOINT` が空のままです。空の場合は、送信時に
   お客さまのメールソフトが開く方式になります。
   「お申し込みフォーム設定ガイド.docx」の手順で設定してください。

3. プロフィール写真の解像度
   顔.png は 269×247px と小さいため、高解像度ディスプレイでは
   やや粗く見える場合があります。可能であれば 600px 角以上の画像に
   差し替えると、より鮮明に表示されます。

4. 瞑想リトリートの開催日
   2026年11月22日／2027年4月・第1日曜午後（予定）と記載しています。
   確定次第、index.html の「次回開催」欄をご更新ください。

5. 「ご利用いただいた方々の声」の掲載内容
   現在の3件は、台本にご感想の原文がなかったため、ご相談内容の傾向をもとに
   こちらで文章を起こした仮のテキストです。そのままでは実際の感想ではありません。
   公開前に、実際にいただいたご感想へ必ず差し替えてください。
   あわせて、掲載についてご本人の同意を得たうえで、年代・性別・タグの表記が
   個人の特定につながらないかをご確認ください。
   実際のご感想がご用意できない場合は、セクションごと削除してください。
   該当箇所：index.html の `<section class="section voice" id="voice">`、
   ヘッダーとフッターの「利用者の声」リンク。

6. 「よくあるご質問」の回答内容
   4問とも台本の内容をもとにこちらで作成した文案です。
   特に秘密保持の例外（生命に関わる場合の関係機関との連携）は、
   実際の運用と一致しているかをご確認のうえ、必要に応じて文言をご調整ください。
   該当箇所：index.html の `<section class="section faq" id="faq">`。

## 予約の受け付け方（2026年9月27日に変更）

外部の予約サイトは使わず、ページ内の「予約希望・お問い合わせフォーム」で受け付けます。
予約ボタン5か所（ヘッダー／ファーストビュー／利用者の声の下／フッター／スマホ固定ボタン）は、
すべて `#reserve`（フォーム）へ移動します。

フォームの設定は index.html の先頭（40行目あたり）で一元管理しています。

```html
<script>
  window.FORM_ENDPOINT = "";
  window.CONTACT_EMAIL = "hiroko.goma@gmail.com";
</script>
```

- FORM_ENDPOINT：Formspree で発行された `https://formspree.io/f/xxxxxxxx` を貼り付けます。
  空のときは、送信ボタンでメールソフトが入力内容入りで開きます。
- CONTACT_EMAIL：お申し込みを受け取るメールアドレスです。フォームの案内文にも表示されます。

料金・お支払い期限・キャンセル条件を変えるときは、次の5か所をそろえて直してください。

- index.html の「ご予約の流れ」下の注記、フォームの「お申し込み前にご確認ください」欄、よくあるご質問5問目
- terms.html（利用規約第4条、キャンセルポリシー）
- tokushoho.html
