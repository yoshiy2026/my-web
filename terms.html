  3. 医療的な治療が必要と思われる場合は、医療機関の受診をおすすめすることがあります。
  4. 本サービスの利用に必要な機器・通信環境・通信料は、利用者のご負担となります。

第3条（お申し込みと契約の成立）

  1. お申し込みは、当方ホームページの「予約希望・お問い合わせフォーム」に、次の事項をご記入のうえ送信する方法で受け付けます。

    2. セッションのご希望日時
    3. ご連絡先（メールアドレスおよび携帯電話番号）
  2. 当方は、お申し込みの受付後、原則として3日以内にメールでご連絡し、日程を調整します。
  3. 日程が決まりましたら、当方からお振込先をご案内します。お支払い期限までに当方がご入金を確認した時点で、ご予約（本サービスの利用契約）が成立します。ご予約の成立後、当方から Zoom の URL をメールでお知らせします。
  4. お支払い期限までにご入金が確認できない場合、そのお申し込みは成立しなかったものとして取り扱います。
  5. 当方は、次のいずれかに当たる場合、お申し込みをお断りすることがあります。この場合、理由をお伝えできないことがあります。
    1. 第10条に定める、本サービスでの対応が難しいご相談であるとき
    2. 過去に本規約に違反したことがあるとき
    3. その他、当方が本サービスを適切に提供することが難しいと判断したとき

第4条（料金とお支払い）

  1. 本サービスの料金は、次のとおりです（税込）。
    • 初回オンライン相談（60分）：3,500円
    • 継続オンライン相談（60分）：5,000円
  2. お支払いは銀行振込（前払い）とし、お支払い期限はご予約日の前日20:00までとします。
  3. 振込手数料は、利用者のご負担となります。

キャンセルおよび日程変更の取り扱いとキャンセル料は、当方が別に定めるキャンセルポリシーによるものとします。

第6条（秘密の保持と個人情報）

  1. 当方は、本サービスを通じて知り得た利用者の個人情報およびご相談内容について、秘密を厳守します。ご本人の同意なく、ご家族を含む第三者に開示・提供することはありません。
  2. 前項にかかわらず、次の場合に限り、必要な範囲で情報を開示し、または関係機関と連携することがあります。
    1. 利用者ご本人または他の方の生命・身体に危険が差し迫っていると判断される場合
    2. 法令に基づき開示を求められた場合
  3. 個人情報の取り扱いは、別に定めるプライバシーポリシーによります。

第7条（禁止事項）

利用者は、本サービスの利用にあたり、次の行為をしてはならないものとします。

  2. 事前のお申し出がなく、当方の了承を得ていない第三者を同席させる行為
  3. 当方または第三者の名誉・信用・プライバシーその他の権利を侵害する行為

第8条（利用の停止）

利用者が前条のいずれかに当たる行為をした場合、または当方が本サービスを続けることが適切でないと判断した場合、当方は、事前の通知なくセッションを中止し、以後のお申し込みをお断りすることができます。この場合、まだ実施していないセッションの料金は返金いたします。

第9条（ご連絡の方法）

  1. 当方とのご連絡は、メールで行います。お電話でのご連絡はお受けしておりません。
  2. 当方からの返信は、原則として3日以内にいたします。
  3. セッションの時間外に、メールなどでご相談に応じることはいたしかねます。

  1. 次のような場合は本サービスでの対応が難しいため、お申し込みをお断りする、または医療機関や公的な相談窓口などへのご相談をおすすめする場合があります。

    2. 医療的な診断、投薬、診断書の作成を目的とする場合

キャンセルポリシー

1. お支払いとご予約の確定

  • お支払い方法：銀行振込（前払い）
  • お支払い期限：ご予約日の前日20:00まで

お支払い期限までに当方でご入金を確認できない場合、そのお申し込みは成立せず、自動的に取り消しとなります（この場合、キャンセル料はかかりません）。

2. キャンセルとキャンセル料

ご予約の成立後（ご入金の確認後）にキャンセルされる場合は、当方がご連絡のメールを受信した日時を基準として、次のキャンセル料を申し受けます。

ご予約日の前日20:00まで
無料
ご予約日の前日20:00以降〜当日
料金の50%
ご連絡がなく、開始時刻から15分を過ぎてもご参加がない場合
料金の100%

ご本人やご家族の急な体調不良・事故など、やむを得ない事情が生じた場合は、ご遠慮なくお知らせください。事情をうかがったうえで、日程の振替など個別に対応いたします。

3. 日程の変更

  • ご予約日の前日20:00までにご連絡いただいた場合、1回に限り無料で日時を変更（振替）いたします。
  • 2回目以降の変更や、前日20:00以降の変更をご希望の場合は、ご相談ください。キャンセル料の対象となる場合があります。

4. 遅刻について

  • 開始時刻に遅れてご参加された場合も、終了時刻の延長はいたしません（ご予約いただいた時間枠のとおりに終了いたします）。
  • ご連絡がなく、開始時刻から15分を過ぎてもご参加がない場合は、ご連絡のないキャンセルとして取り扱います。
  • 当方の都合で開始が遅れた場合は、その分の時間を延長するか、ご希望に応じて返金いたします。

5. 通信トラブルへの対応

  • 当方側の通信障害や都合によりセッションが実施できなかった場合、または途中で続けられなかった場合は、全額返金、またはご希望に応じて日程の振替をいたします。
  • 利用者側の通信環境の不具合によりつながらなかった場合は、後日への日程の振替など、個別に対応いたします。

6. 返金について

  • キャンセルなどに伴う返金は、ご指定の口座へのお振込みにて、原則として7日以内にいたします。
  • 利用者のご都合による返金の場合、振込手数料は利用者のご負担となります（手数料を差し引いた金額をお振込みいたします）。
  • 当方の都合や当方側の通信障害による返金の場合、振込手数料は当方が負担いたします。

7. キャンセル・変更のご連絡先

キャンセルや日程変更のご連絡は、メール（hiroko.goma@gmail.com）でお願いいたします。
